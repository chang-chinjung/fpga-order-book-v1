# V1.2.1 實作規格 — 時序修正（Fmax ≥ 130 MHz）

> 前置：v1.2 功能全部達標（48/48 directed、34,000 筆隨機、接受率 0.500 cmd/cycle、
> 突變 100%、覆蓋率 95.7%、延遲 14 cycles），**只有 Fmax 未達標**：
> 107.30 / 111.64 / 122.10 MHz（門檻 130）。

## 目標

- 三個 placement seed 的**最差 Fmax ≥ 130 MHz**
- 延遲上限放寬到 **≤ 16 cycles**（可以再加一級）
- **其他門檻全部不變**：48 directed、34k 隨機、接受率 ≥ 0.5、突變 ≥ 95%（目標 100%）、
  覆蓋率 ≥ 95%、BRAM 76、lint 0

## 根因（已確認）

- v1.1 單商品：39 DP16KD → 122.19 MHz
- v1.2 雙商品：76 DP16KD → 107.30 MHz
- 邏輯延遲已壓到 1.7–2.1 ns；瓶頸是**跨 BRAM row 走線 6.0–6.6 ns**

## 允許的改法

1. **在 BRAM 寫回路徑加一級暫存**（ladder qty / count / head / tail 各一組）
2. **把 shadow BRAM 的寫入資料暫存搬到 DP16KD 旁邊**（每商品各一組，縮短跨區走線）
3. **best-price 路徑再加一級**（bitmap 更新與輸出分離）
4. 必要時把 `ord_rd_addr` 的選擇邏輯提前一級
5. 小幅 floorplan 調整（若工具支援）

## 不可變

- 語意（TRADE 選邊、seq gap、snapshot、多商品隔離）
- 既有 48 個 directed 的預期值
- 接受率 ≥ 0.5 cmd/cycle（加管線不可讓 cadence 掉回 3 cycles）
- 突變分數 ≥ 95%

## 驗收

| # | 項目 | 門檻 |
|---|---|---|
| 1 | 既有 48 directed + 34k 隨機 | 全過 |
| 2 | 接受率 | ≥ 0.5 cmd/cycle |
| 3 | 突變 | ≥ 95%（目標 100%） |
| 4 | 覆蓋率 | ≥ 95% |
| 5 | **Fmax** | **≥ 130 MHz（3 seeds 最差）** |
| 6 | 延遲 | ≤ 16 cycles |
| 7 | 資源 | DP16KD ≤ 80 |
| 8 | lint | 0 warning |

## 若 130 仍達不到

**照實回報**：三個 seed 的數字、加了幾級、每一級切在哪個路徑、剩下最長路徑是什麼。
不要為了達標而降低測試強度或改語意。

## 實作順序

1. 先量目前最長路徑（哪一條 net、跨幾個 row）
2. 只在該路徑加一級，量 Fmax
3. 不夠就再加一級到 best-price 路徑
4. 每加一級都要重跑：sim、接受率、突變
